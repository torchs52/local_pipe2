# 動作確認・性能測定手順

## 本体アプリのみでの動作確認の手順

1. `git clone [-b　xxx]` でソースコードを取得する。
2. argus_synchro_refactoringをJetsonのホームディレクトリに配置して、名前をargus_synchroに書き換える。
3. ターミナルでargus_synchroを開く。
4. make allでインストールを実施する。
5. 動作確認を実施する。
   * 基本:
      * `make run`
   * UIを同時起動する場合:
      * `make run-with-ui`
   * `config` や`log`,`mmap`のディレクトリを変更する場合:
      * `python scripts/run_argus.py run --config-dir ./config --log-dir ./log --mmap-dir /dev/shm`
   * `config` ディレクトリを変更しつつUIを同時起動する場合:
      * `python scripts/run_argus.py --config-dir ./config run --with-ui`
   * 補足:
      * `run_argus.py` は実行環境を自動判定し、実行中のみ設定ファイルを差し替える。
         * `config/settings.ini` ← `config/settings_jetson.ini` または `config/settings_wsl.ini`
         * `config/SCX900-3_settings.ini` ← `config/SCX900-3_settings_jetson.ini` または `config/SCX900-3_settings_wsl.ini`
      * `--with-ui` 指定時は `argus_godot_ui/settings/godotSettings.cfg` 内の絶対パスも実行中のみ置換する。
         * 置換元: `/home/shiuser/argus_pipe_filter/`
         * 置換先(既定): `run_argus.py` があるリポジトリのルート絶対パス
         * 変更する場合:
           `python scripts/run_argus.py run --argus-root-dir /path/to/argus_root`
      * 実行終了時（エラー終了を含む）に自動復元する。
         * `settings.ini.backup.run`
         * `SCX900-3_settings.ini.backup.run`
         * `godotSettings.cfg.backup.run`

## UIアプリを含めた動作確認の手順

1. 本体アプリのみでの動作確認の手順を実行する。
   * `make run-with-ui`を使う。

## 本体アプリのみでの性能測定手順

1. 対象のブランチをチェックアウトまたはソースコードを取得する。
2. argus_synchro_refactoringをJetsonのホームディレクトリに配置して、名前をargus_synchroに書き換える。
3. VSCodeは閉じる。
4. ターミナルでargus_synchroを開く。
5. make allでインストールを実施する。
6. 性能測定を実施する。
   * 基本（全区間を実行）:
      * `make prof`
   * UIを同時起動する場合:
      * `make prof-with-ui`
   * 出力先を指定する場合:
      * `python scripts/run_argus.py prof --base-dir /mnt/nvme/test`
   * 実行対象を1つに絞る場合:
      * `python scripts/run_argus.py prof --profile-scope section1`
      * `python scripts/run_argus.py prof --profile-scope section2`
      * `python scripts/run_argus.py prof --profile-scope section3`
      * `python scripts/run_argus.py prof --profile-scope overall`
   * `config` や`log`,`mmap`のディレクトリを変更する場合:
      * `python scripts/run_argus.py prof --config-dir ./config --log-dir ./log --mmap-dir /dev/shm`
   * `config` ディレクトリを変更しつつUIを同時起動する場合:
      * `python scripts/run_argus.py --config-dir ./config prof --with-ui`
   *  補足:
      * `run_argus.py` は実行環境を自動判定し、計測中のみ `config/settings.ini` を環境別の性能測定設定に差し替える。
         * Jetson: `config/settings_jetson_prof.ini`
         * それ以外: `config/settings_wsl_prof.ini`
      * 計測中は `SCX900-3_settings.ini` も環境別設定へ差し替える。
         * Jetson: `config/SCX900-3_settings_jetson.ini`
         * それ以外: `config/SCX900-3_settings_wsl.ini`
      * 計測開始時に以下を退避し、計測終了時（エラー終了を含む）に自動復元する。
         * `settings.ini.backup.prof`
         * `SCX900-3_settings.ini.backup.prof`
         * `godotSettings.cfg.backup.prof`

## 動作確認手順以外で許可すること

- ortのキャッシュをコピーして再利用する。

## 認識合わせをしたうえで許可されること

- 性能測定スクリプトの実施範囲、測定タイプを変更する。
- make installを実施せず、.venvを再利用する。
以下、T.B.D.
- Jetsonで校正モード実施時、config/calib_settings.iniのcheckpointsのパスを変更する。
